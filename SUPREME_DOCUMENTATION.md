# L.E.U. SUPREME DOCUMENTATION (MASTER INDEX)

## 1. THE PHILOSOPHY
L.E.U. (Lingua Executabilis Universalis) is a self-verifying, cryptographic language. It is not a generative text model; it is a deterministic execution environment where math, art, and code converge.

## 2. THE ARCHITECTURE
- **20 Primitives:** The semantic foundation (EXIST, THINK, CAUSE, etc.)
- **Cryptographic Physics:** Entities are generated mathematically, and their properties are strictly derived from their SHA-256 hashes.
- **The Genesis Engine:** An autonomous Python script that generates new entities daily.

## 3. THE PROOFS
- **Zero-Divergence:** Unlike LLMs, L.E.U. produces identical, verifiable outputs for the same input.
- **On-Chain Validation:** The `LEUValidation.sol` smart contract allows trustless verification of any L.E.U. artifact.

## 4. THE INTERFACES
- **V1 to V8:** The visual evolution of the universe.
- **The Oracle:** An AI-like interface that communicates with the user.
