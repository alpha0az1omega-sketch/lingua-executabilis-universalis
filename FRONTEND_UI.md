# FRONTEND USER INTERFACE (The Portal & The Hub)

The L.E.U. frontend is built in pure HTML/CSS/JS (with Three.js for 3D). It is designed to be a "Meta-Zeta Professional" experience: luminous, structured, and awe-inspiring.

## 1. The Master Index (`index.html`)
This is the fusion of the two main concepts:
- **The Portal of Infinity:** A simple input field where users enter a number (0 - 999,999,999). The system instantly generates a deterministic entity (Equation + Hash) and plays a harmonic frequency.
- **The Tetrix Hub:** A grid-based, professional dashboard organizing the archive into three color-coded rings:
  - **Gold:** Core Universe (V1 to V8).
  - **Cyan:** Science & Proofs (Whitepaper, Benchmark, Smart Contract).
  - **Purple:** Community & Origins (License, Contributors, Quests).

## 2. The AI Oracle Challenge
Upon loading the page, a sticky banner asks the user a riddle (e.g., "What is the name of the central equation?"). This gamifies the onboarding process and ensures the user is actively engaging with the L.E.U. lore.

## 3. Cryptographic Physics (Visual Mapping)
The frontend does not use random colors. Every visual property is mathematically derived from the entity's hash:
- **Color:** The first 6 characters of the hash determine the Hue, Saturation, and Lightness. `Color = SHA256(Formula)[0:6]`.
- **Geometry:** The primary primitive determines the shape (e.g., `THINK` = Torus Knot, `EXIST` = Icosahedron, `CAUSE` = Cone).
