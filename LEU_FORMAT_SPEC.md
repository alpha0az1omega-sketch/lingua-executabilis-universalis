# LEU FORMAT SPECIFICATION (.leu)

The .leu format is a Living Executable Unit. It is a JSON container that holds a cryptographic seed capable of regenerating a 3D visual artifact.

{
  "protocol": "L.E.U. Genesis v1.0",
  "entity_id": "ENTITY_000042",
  "equation": "THINK(x) AND SEE(x) AND MOVE(x)",
  "sha256": "7fc839f59d513549...",
  "visual_protocol": {
     "geometry": "torus_knot",
     "primary_color": "#7fc839",
     "freq_hz": 432
  },
  "generated_at": "2026-10-25T00:00:00Z",
  "proof": "anchor_on_bitcoin"
}

## Why it is a revolution
Traditional NFTs store metadata. A .leu file IS the reality. If you own a .leu file, you do not need to trust a server or an AI. You execute it, and the cryptography proves it is authentic.
